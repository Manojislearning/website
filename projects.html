Project Case Study: Sapthagiri Hospital Glass Façade BIM

Detailed Project Overview

Project Overview

Sapthagiri Hospital required a comprehensive BIM-based glass façade model for a new outpatient wing. The project demanded precise LOD 400 modeling with panel numbering, fabrication schedules, and installation documentation.

Challenge

  • Complex curved glass façade requiring parametric modeling
  • 500+ individual glass panels requiring unique numbering
  • Coordination with MEP systems and structural elements
  • Accurate quantity extraction for fabrication and procurement

Solution

  • Developed parametric glass panel family in Revit
  • Used Dynamo scripting for automated panel numbering
  • Created comprehensive schedules for mullions, panels, and hardware
  • Performed clash detection with MEP and structural elements
  • Generated shop drawings and fabrication documentation

Results

500+

Uniquely numbered and scheduled glass panels

30%

Cost savings through accurate BOM

100%

Clash-free coordination

12

Comprehensive schedules & details

Deliverables

  • LOD 400 Revit model
  • Façade elevations with panel numbering
  • Component schedules (panels, mullions, hardware)
  • Shop drawings and details
  • Navisworks coordination file
  • BOQ and quantity reports
